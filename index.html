一、核心方法架构：三层解耦联邦 MoE 与四项原创机制 1. Architecture: Three-Tier Decoupled Federated MoE

不同于通用文本联邦微调，移动端 GUI 动作具有严格的 <tool_call>{"action": "open", "app": "..."}</tool_call> 结构化语法，且真实用户端侧交互流无人工偏好标签、混杂偶发反向操作（如惯用 Spotify 的用户临时点开一次 YouTube Music）。本框架通过四项协同机制实现精准解耦：

Mobile GUI agents emit structured <tool_call> actions where universal UI syntax and user-conflicting app/entity choices coexist within a single sequence, trained over noisy, unlabeled on-device streams. FedGUI-MoE resolves this via four synergistic mechanisms:

1. 双视图非对称历史遮蔽（Asymmetric History-Dropout）

1. Dual-View Asymmetric History-Dropout

在核验习惯步上以 70% 零历史完整序列视图 + 值段对比边际训练本地私有层，切断“照抄提示词历史”捷径，迫使私有适配器建立真正的参数化习惯记忆。

Trains the private adapter with a 70% history-masked full-sequence view plus value-span margin, eliminating context-copying shortcuts and building genuine parametric memory.

2. BPE 安全的亚句级隔离与双层异常阻断

2. BPE-Safe Span Isolation & Dual-Tier Outlier Blocking

通过哨兵探针精确剥离 <tool_call> 工具骨架与分叉参数值；对无标签筛出的偶发反向样本同时阻断私有与共享层的参数值更新，根除“反向异常倒灌”。

Uses sentinel probes to separate shared tool syntax from user-specific argument spans; blocks detected one-off outliers from both private and shared value updates.

3. 分语种折叠去均值 VLM 语义路由

3. Language-Folded Mean-Centered VLM Routing

仅基于公开锚点按中/英语种独立拟合公共均值中心，将冻结 VLM 隐空间原型余弦从 0.9955 压降至 -0.3222，判别间隔放大 153.6×，零私人特征上传。

Calibrates language-specific public centers without touching client data, reducing off-diagonal prototype cosine from 0.9955 to -0.3222 (153.6× margin gain).

4. 统一秩分配与 Top-1 主导域稀疏上传

4. Unified Budget & Top-1 Dominant Sparse Upload

采用 Global(r=3) + DomainShared(4×r=1) + Private(r=4)，每轮仅上传全局层与单一主导域专家（总秩 4），实现与单域 FDLoRA (F2) 严格 1.00× 存储与 1.01× 通信对齐。

Allocates Global(3) + Shared(4×1) + Private(4) and uploads only Global plus the client's top-1 dominant domain slice per round (3+1=4 rank parity).

三、三项关键科学发现 3. Three Key Empirical Findings

Finding 01 · Scaling Law

上下文捷径饥饿反尺度律

In-Context Shortcut Starvation Law

在常规联邦微调（F2）中，基座从 2B 增至 8B 时，更强的上下文复述能力使共享层迅速靠“抄写提示词历史”压低训练损失，反而剥夺本地私有适配器的有效梯度（EN 8B 零历史准确率跌至 5.00%，CN 4B 甚至低于未训练基座）。非对称历史遮蔽将该留存率恢复至 66.3%–89.0%。

As VLM backbones scale from 2B to 8B, stronger in-context copying starves local private adapters of gradient signal under standard pFL (F2 drops to 5.00% zero-history SSR at 8B, and below the frozen base on CN 4B). Asymmetric History-Dropout restores 66.3%–89.0% retention.

Finding 02 · Noise Robustness

反向异常倒灌现象与双层阻断

Anti-History Outlier Leakage

若仅用互补权重 (1 - c_t) 将被私有层拒收的 15% 偶发反向样本导流至共享层，会导致共享层集中学习“违背上下文历史”的反向映射并引发 Oracle < No-Screen 倒挂。双层取值阻断切断异常参数值向双支路的泄漏，无标签拦截 88.9% 异常并消除上界倒挂。

Routing rejected stream outliers into shared adapters via complementary (1 - c_t) weights poisons shared context-following and triggers Oracle < No-Screen inversion. Dual-tier value blocking intercepts 88.9% of outliers without labels and restores monotonic gains.

Finding 03 · Representation

多语种 VLM 隐空间锥塌缩消除

Multilingual Cone-Collapse Removal

冻结多模态基座的原始任务隐向量呈高度各向异性锥塌缩（跨领域余弦达 0.9955），且混合单均值受语种偏移主导。仅用公开描述执行中/英分语种均值折叠中心化，无需上传任何本地特征即可实现双语 90.0% 留一路由准确率。

Raw frozen VLM task embeddings suffer severe cone collapse (0.9955 off-diagonal cosine) and language-axis dominance. Language-folded public-anchor mean centering achieves 90.0% bilingual leave-one-out routing accuracy with zero client feature upload.
