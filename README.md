## 核心研究概览

移动端多模态 GUI 智能体（Mobile GUI Agents）在面对日常欠指定模糊指令（如桌面状态下 *“放首歌听”*、*“搜索我想买的商品”*）时，需要在保护端侧隐私的前提下兼顾**全网通用界面操作能力**与**跨领域个人应用/实体习惯**。现有联邦参数高效微调（如 `FDLoRA`）在真实移动端流上暴露出三大瓶颈：

1. **上下文捷径饥饿（In-Context Shortcut Starvation）**：当提示词包含检索历史时，高容量基座倾向于直接机械复述历史文本，剥夺本地私有适配器的有效梯度；一旦遇到检索缺失或冷启动（`History-Drop 100%`），传统方法准确率断崖式塌缩（甚至低于未微调基座）。
2. **结构化动作内语法与习惯耦合**：单条 GUI 工具调用 `<tool_call>{"action": "open", "app": "..."}</tool_call>` 内，90% 工具语法骨架跨用户一致，仅参数值跨用户冲突。
3. **无人工标签流上的偶发反向噪声**：真实交互流无逐步偏好标注且混杂约 `15%` 偶发反向操作（如惯用网易云/Spotify 的用户偶尔点开一次 QQ音乐/YouTube Music），单层拦截若将异常导流至共享层会引发“反向异常倒灌”。

**FedGUI-MoE（V3.1）** 在严格对齐单域基线 **`1.00×` 客户端私有存储** 与 **`1.01×` 上传通信开销** 的前提下，通过 **① 分语种公开锚点去均值 VLM 路由（判别间隔放大 `153.6×`，留一准确率 `90.0%`）**、**② 无标签双准则自筛选与双层异常阻断（拦截率 `88.9%`）**、**③ BPE 安全的亚句级区间隔离与三组独立梯度裁剪**、以及 **④ 双视图非对称历史遮蔽（70% 零历史视图）** 解决上述难题。
